# FoxsMusic 1.3.12 — Halloween Pumpkin Without Eyes

- Replaced the central Halloween pumpkin asset with an opaque crimson pumpkin that has a glowing jagged grin but no eyes.
- Removed the pumpkin eye-blink overlay so no artificial eyelids appear on the pumpkin.
- Kept the four separate animated side eyes, their blinking/gaze motion, the skull backdrop, pentagram, levitating candles, flames, bats, ghosts, wind and embers.
- The rest of the player is unchanged.

Build on Windows: run `build-windows.bat`, then use the portable executable in `release`.
