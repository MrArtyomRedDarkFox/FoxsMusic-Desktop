# FoxsMusic Desktop 1.3.21 — Localization consistency fix

This update improves the Russian, English and German UI translations.

- Translates static interface copy that was previously left in Russian.
- Localizes dynamically created dialogs, labels, image descriptions and notifications.
- Fixes empty-library messages and queue labels when changing languages.
- Localizes sound-studio crossfade units and the hero sound status.
- Keeps user-created track, artist, album and playlist names unchanged.

The selected language is still saved in the existing application settings.
