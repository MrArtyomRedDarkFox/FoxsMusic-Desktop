# FoxsMusic 1.3.8 — Illustrated Halloween Profile

This update refreshes only the Halloween banner artwork and its animation layers.

- Replaces the ritual scene with cleaner cel-shaded illustration artwork, closer to the illustrated Christmas profile.
- Uses a wide, transparent artwork asset sized to the banner, with the pumpkin, pentagram and five candles centered together.
- Adds four watching side eyes: two horizontal and two tilted at -120° / +120°.
- Keeps individual flame overlays and warm glows animated at different speeds.
- All effects remain controlled by the in-app visual-effects toggle.

Build on Windows with `build-windows.bat`. The app version is 1.3.8.
