# FoxsMusic 1.3.18 — F11 Fullscreen

- `F11` toggles native Electron window fullscreen (works even when the search field is focused).
- The toolbar fullscreen button and the existing `F` shortcut use the same native fullscreen toggle.
- The keyboard-help panel now shows `F / F11`.
- No playback, library, theme, or seasonal animation logic was changed.

Build on Windows by running `build-windows.bat`; the portable artifact will include version 1.3.18 in its filename.
