# FoxsMusic Desktop — исправления 1.3.23

## Что исправлено

- Исправлен устаревший smoke-тест локализации: теперь он проверяет корректный формат версии и согласованность `package.json` с обеими версиями в `package-lock.json`, вместо жёсткого ожидания старой версии `1.3.22`.
- Ошибка чтения встроенной обложки больше не должна мешать поиску внешней обложки в папке трека. Сообщение в консоли стало короче и понятнее; обработка метаданных по-прежнему защищена `try/catch`.
- Сохранены существующие проверки дат исходных файлов, разделения даты исходного файла и даты импорта, а также выравнивания кнопок удаления.

## Запуск в Windows

Из папки проекта в терминале CMD:

```cmd
npm.cmd install
npm.cmd start
```

Если PowerShell блокирует `npm`, используйте терминал **Command Prompt (cmd)** в VS Code. Команда `npm.cmd` позволяет вызвать npm без изменения системной политики выполнения PowerShell.

## Примечание об обложках

Если конкретный MP4-файл содержит повреждённые или нестандартные метаданные, FoxsMusic пропускает встроенную обложку и пытается найти рядом с файлом изображение вроде `cover.jpg`, `folder.png` или изображения с именем трека. Это предупреждение само по себе не означает, что аудиофайл повреждён.
