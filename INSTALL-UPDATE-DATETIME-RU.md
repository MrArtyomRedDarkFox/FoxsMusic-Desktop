# Установка обновления FoxsMusic: дата и время добавления

1. Закрой FoxsMusic Desktop.
2. Сделай копию своей текущей папки проекта или используй встроенную резервную копию.
3. Распакуй архив `FoxsMusic-Desktop-updated-import-datetime.zip` в отдельную папку.
4. Скопируй из распакованного проекта в свою рабочую папку следующие файлы с заменой:
   - `app.js`
   - `styles.css`
   - `package.json`
   - `README.md`
   - `tests/added-timestamp.test.cjs`
5. Открой терминал PowerShell в корне проекта и выполни:
   ```powershell
   node --check .\app.js
   node .\tests\added-timestamp.test.cjs
   npm.cmd test
   ```
6. Запусти приложение:
   ```powershell
   npm.cmd start
   ```

Что изменено:
- В обычном списке у каждого трека показывается дата и время импорта в FoxsMusic.
- В «Недавно добавленных» показывается дата изменения исходного файла и отдельной строкой — когда трек был добавлен в FoxsMusic.
- В «Часто прослушиваемых» счётчик воспроизведений остаётся основным значением, а дата добавления выводится ниже.
- Полная дата/время доступна в подсказке при наведении.
- Добавлены RU/EN/DE подписи.
- Новый тест добавлен в `npm test`.

Примечание:
`addedAt` — момент импорта в FoxsMusic; `sourceDateAt` — время последнего изменения исходного файла. Эти значения разные и не должны перезаписывать друг друга.
