# FoxsMusic Desktop 1.3.19 — удаление пользовательских пресетов

## Изменения
- В звуковой студии рядом с каждым пользовательским пресетом появилась кнопка удаления.
- Перед удалением показывается подтверждение.
- После подтверждения пресет удаляется из сохранённых настроек и сразу исчезает из списка.
- Встроенные пресеты Flat, Bass+, Vocal и Night не затрагиваются.

## Проверка
Проверены синтаксис `app.js`, `main.cjs`, `preload.cjs` и выполнен `npm test`.
